# Release Notes

## 1.0.0 — 2026-11-15

- Introduced the seven-page sidebar workspace: Dashboard, Optimizations,
  Performance, Backups & Restore, Activity Logs, Settings, and About.
- Added persistent workspace appearance, scaling, and startup-scan settings.
- Retained the existing reversible optimization engine, backup system, process
  monitoring, cache safeguards, and Spicetify integration.
- Removed obsolete standalone log/results panels and unreferenced screenshot
  capture artifacts.

The release executable is built from `spotify_optimizer.spec` and placed in
`release/` after verification.
